読み方 // 3 手順

  1. 00 と 08 を先に読む。どのファイルが何を担当しているかの表を持ってから本文に入ると、迷子にならない。
  2. 図 → 該当章 → ソース。図で「どこからどこへ何が動くか」を掴み、章で理由を読み、最後に .cu を開く。
  3. 数値は暗記しない。帯域・温度・ブロックサイズは環境で変わる。覚えるのは構造（層の数、行き先の種類、切れ目）だけ。
